# The Red Ledger (红色账簿)

[English](README.md) · [한국어](README.ko.md) · **中文**

一个 [杀戮尖塔 2](https://store.steampowered.com/app/2868840/) 模组：在商人处**借金币**买下你差一点付不起的东西，然后慢慢还清这笔债——或者被它压垮。

## 核心循环

1. **借款。** 在商店里，付不全的物品也能买下——差额由商人借给你（有上限）。你会获得记录债务的**债务账本**遗物。
2. **利息增长。** 你要还的比借的多：借款时立即产生的手续费，加上每经过一个房间就累积的利息。拖得越久，代价越高。
3. **拖欠 → 诅咒。** 债务背得太久，会有不断升级的**债务**诅咒牌渗入你的战斗——**逾期**，接着**扣押**，最终是**信用不良**及其无休止的**强制催收**。
4. **偿还。** **定期还款**能力每回合塞给你**还款**牌——打出一张即可花费金币削减本金。**在之后的商店**（绝不能是借款的那一家）偿清本金即可结清。账本与还款牌都会保留，只有**债务等级**会重置为 1，诅咒随之停止，你也可以再借。
5. **信用度。** 你偿还过的全部金额会累积为**信用度**——这是一条**即使结清也不会重置**的整局轨道。每达到一档就解锁一份由你自己领取的奖励；越过最高一档后仍会继续产出，让你一次又一次地升级或移除卡牌。

## 债务商店

一旦欠债，专门的**债务商店**允许你**赊账**购买还款类卡牌，其价格会计入你所欠的债务。货架每次到访都会轮换：一张免费、一张打折，其余售价 45~95 金币。每家商店设有**赊账额度**（默认 120 金币），于是每次到访都是同一个抉择——*一张高价卡，还是标价之和不超过 120 的两张？* 商店同样以赊账方式出售卡牌移除。

## 还款引擎

你每完成一次还款都会积攒**收据**——一种拥有独立计数器的战斗资源。*还款*牌打出时获得 1 张，若支付了金币则为 2 张。你收集到的还款牌会将收据兑现：

- **还款能力** — *还款优惠*、*返还*、*利息补贴*等会在每次还款时触发，返还格挡、卡牌或金币。
- **消耗收据的卡牌**会随你积攒的收据数量增强：*结算*将其转化为格挡，*账单*转化为多段攻击。
- **催收**把整个循环转为进攻——每回合塞给你一张*强制执行*令牌，消耗一张收据换取**活力**（强化下次攻击）。

## 以债为资

还清并非唯一的玩法。发放诅咒的那本账本同样发放抵押——这些卡牌按**你仍背负的债务**给你回报：

- **抵押** — 每 45 金币债务提供 1 点格挡（升级后 34）。
- **违约风险** — 每 250 金币债务提供 1 点力量（升级后 180），打出时结算一次。
- **坏账** — 手牌中每有 1 张诅咒便造成 5 点伤害。只计数，**不消耗**。
- **扣押物** — 0 费、消耗、8 点格挡，战斗开始时洗入抽牌堆。**张数**随剩余债务阶梯上升（250 / 500 / 750 金币 → 1 / 2 / 3 张）。奖励取决于*债务的规模*而非*拖延的时间*，所以单纯拖着并不划算。

于是“何时抽身”成了真正的抉择，而不是一段倒计时。

## 宣告破产

当债务堵塞你的牌组时，**宣告破产**会消耗你持有的所有债务牌，并将这堆残骸转化为**力量**——但本场战斗中你将无法获得金币。这是为深陷债务的牌组准备的一次全押式转型。

## 合作 (多人)

债务是共同承担的负担：

- **传染** — 队友的贷款也会渗入*你的*战斗。
- **人多更狠** — 欠债的玩家越多，利息累积得越快、越高。
- **代偿 (대납)** — 仅限多人的卡牌，替队友偿还一部分债务。当有人错过还款时，最富裕的盟友会得到一张代偿牌，好帮他还债。

## 配置 (游戏内 ModConfig)

最大贷款额（0 表示不限）、每笔贷款的提取次数、赊账购卡的每店额度、利息达到上限后从金币收入中代扣的比例，以及总利息上限。

## 构建

本模组是作者 monorepo 的一部分，依赖共享的 **Sts2.ModKit** SDK（csproj 中的 `..\Sts2.ModKit\build\Sts2.ModKit.props`）。若要独立构建，请将该 import 指向一份 Sts2.ModKit 副本。

- **DLL：** `dotnet build Sts2DebtLoan.csproj -c Release` → 部署到 `Slay the Spire 2/mods/Sts2DebtLoan/`。
- **资源包**（遗物/卡牌美术、本地化）：由 `pck_src/` 通过 Godot 4.5.1 `--export-pack` 构建 → `Sts2DebtLoan.pck`。
